# 05｜计算机视觉入门：先做一个小模型

计算机视觉就是让计算机从图片或视频中提取信息。常见任务包括：

- **分类**：给整张图一个类别，例如猫或狗；
- **检测**：找出图中物体，并画出方框；
- **分割**：给每个像素标出属于什么物体；
- **跟踪**：在连续视频帧中追踪同一目标。

建议从图像分类开始，因为实验流程较短、容易检查。

## 学习顺序

1. Python基础、列表、函数和读取文件；
2. NumPy数组，理解图片是由像素数字组成；
3. 训练集、验证集、测试集分别是什么；
4. 运行PyTorch官方Quickstart；
5. 复现官方迁移学习教程；
6. 查看错误样例和混淆矩阵；
7. 比较模型速度、准确率和运行能耗时，固定设备和测试条件。

## 先知道的几个词

- **训练集**：模型用来学习的数据；
- **验证集**：开发时用来选择设置的数据；
- **测试集**：最后评价模型的数据，应尽量保持不参与调参；
- **过拟合**：模型记住训练样本，却无法处理没见过的样本；
- **基线**：一个简单、可信的起点，后续方案要与它公平比较；
- **迁移学习**：先使用在大数据上学过的模型，再用较小的新数据调整。

## 研究实验最少记录

模型名称/版本、数据集和许可、训练/验证/测试划分、输入尺寸、数据增强、随机种子、软件和硬件、训练时间、推理延迟、准确率及其他相关指标、失败样例。若测能耗，说明仪器/数据来源、边界和误差；不能测就标为估算或不测。

## 碳排放关联的注意事项

更高准确率不必然意味着更低碳；更快推理也不必然意味着总排放更低。比较时要固定完成的任务量和质量要求，并说明功率、PUE和电力碳强度来源。不要仅凭模型参数量推断实际耗电。
