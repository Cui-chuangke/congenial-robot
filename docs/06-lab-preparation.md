# 06｜准备加入实验室：用证据表达兴趣

目标不是把自己包装成已经会做研究，而是让老师看出你做过准备、知道自己的能力边界、可以完成小任务并持续汇报。

## 公开信息调研表

- 教师姓名与院系：
- 实验室主页：
- 最近三年代表性论文（至少读摘要和方法）：
- 论文研究任务：分类/检测/分割/其他
- 使用的数据集：
- 代码是否公开：
- 实验室近期招生或本科生项目公告：
- 页面链接与访问日期：
- 我最感兴趣的具体问题：
- 我还不懂的概念：

只引用学校、实验室、论文、官方项目等可核验来源，不根据传闻推测老师的招募计划。

## 一页能力摘要

| 内容 | 证据 |
|---|---|
| Python：会做什么 | 代码或项目链接、截图、结果 |
| 数据处理：会做什么 | 输入数据、清洗步骤、输出文件 |
| 视觉入门：完成什么 | 数据集、基线、指标和限制 |
| 阅读论文：读过什么 | 标题、方法摘要、一个疑问 |
| 可投入时间 | 每周小时数、考试期间安排 |
| 正在补的能力 | 明确而诚实地写出 |

## 邮件模板

```text
主题：本科科研咨询——计算机视觉方向

尊敬的X老师：

您好！我是[学校/专业/年级]的[姓名]。我读了您关于[具体论文或方向]的工作，尤其对[具体问题]感兴趣。

我目前在学习Python和计算机视觉，已经完成[真实完成的项目/练习及证据]，正在补充[尚在学习的内容]。我也参加能源经济学术创意大赛，研究兴趣涉及AI服务碳核算；我理解这与实验室的视觉研究并不完全相同，希望先从实验室实际需要的小任务学习。

想请教您是否有适合本科生的入门任务，或您建议我先完成哪些准备？我每周可投入约[小时数]。附上[代码/一页摘要/阅读笔记]供您参考。

感谢您阅读。

此致
敬礼
[姓名]
[学校、专业、年级]
[邮箱]
```

只写已经完成的项目；不要夸大能力或假装已经复现论文。

## 交流时可以问

- 本科生第一项任务一般是什么？
- 哪些基础是开始前必须具备的？
- 是否有公开数据和可复现基线？
- 如何提交代码和实验记录？
- 实验室通常如何沟通进展？
- 一周最低投入时间是多少？
- 项目数据、作者署名和成果使用如何约定？
