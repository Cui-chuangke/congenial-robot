# 02｜研究工作簿：从题目到可验证问题

本工作簿是空白研究辅助表，不提供预设结论。请自行选择对象并填入来源。

## B. 功能单位卡

“功能单位”就是你规定的共同尺子。把下面句子补完整：

> 本研究比较的是：在____（质量/条件）下，完成____（任务数量）项____（任务）。

例子仅供理解：在相同测试集上完成1000张图片分类。真正研究中要说明数据集、图像尺寸、模型和准确率要求。

## E. 变量与计算

| 变量 | 含义 | 单位 | 数据来源 | 测量/估算/假设 |
|---|---|---|---|---|
| 设备功率 |  | kW |  |  |
| 运行时间 |  | h |  |  |
| PUE | 数据中心总能耗与IT设备能耗的比值 | 无量纲 |  |  |
| 电力碳强度 | 每单位电力对应的排放 | kg CO2e/kWh |  |  |

在研究边界仅为运行用电时，可用：

`运行排放 (kg CO2e) = 功率 (kW) × 时间 (h) × PUE × 电力碳强度 (kg CO2e/kWh)`

注意：若功率已经是整个数据中心总功率，再乘PUE会重复计算。先核对功率定义。若有设备利用率或共享资源分摊，需要另外解释其定义和算法。

## F. 数据来源质量

每条数字标记一种：

- **实测**：仪器或服务计量直接测到，并记录方法；
- **披露**：机构公开报告的值；
- **基准**：来自行业或文献，代替缺失值；
- **假设**：研究者为情景分析设置；
- **未知**：没有找到可信数据。

不可把基准值或假设值说成某家公司实测数据。

## G. 结果检查

- 单位是否一致？
- 地区和年份是否一致？
- 比较对象是否完成同一功能？
- 是否把训练排放分摊到每次推理？如有，方法是什么？
- 哪些生命周期阶段没算？
- 输入增加或减少时，结果是否按预期变化？
- 是否能由另一人用同一数据复算？
- 结论是否只针对本研究范围？
