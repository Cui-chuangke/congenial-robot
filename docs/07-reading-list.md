# 07｜可靠资料入口与阅读顺序

以下是原始或官方资料入口。标准和法规通常较专业；先读摘要、定义和适用范围，不必一开始购买或通读全文。请确认最新版本，记录访问日期。

## 赛事规则

- [全国大学生能源经济学术创意大赛官网与报名入口](https://energy.qibebt.ac.cn/eneco/contribution/index.html#/index)
- 赛事通知在不同高校网页可能是转载；涉及时间、作品格式和AI使用政策时，以大赛官网发布的当届文件为准。

## AI环境影响与生命周期评估

- [ITU-T Recommendation L.1801](https://www.itu.int/ITU-T/recommendations/rec.aspx?rec=L.1801)：AI系统环境影响评估指南，基于生命周期评估方法；重点关注目标、边界、功能单位、数据和不确定性。
- [ISO 14040概览](https://www.iso.org/standard/37456.html)：生命周期评估原则与框架。标准全文可能需要购买。
- [ISO 14044概览](https://www.iso.org/standard/38498.html)：生命周期评估要求与指南。标准全文可能需要购买。
- [GHG Protocol Corporate Standard](https://ghgprotocol.org/corporate-standard)：组织温室气体核算与报告标准。
- [GHG Protocol Scope 2 Guidance](https://ghgprotocol.org/scope-2-guidance)：购入电力等间接排放核算指南。

## 数据中心与能源

- [国际能源署（IEA）数据与统计](https://www.iea.org/data-and-statistics)：能源数据入口；使用前核对具体指标定义、年份和地区。
- [IEA数据中心专题](https://www.iea.org/energy-system/buildings/data-centres-and-data-transmission-networks)：数据中心和数据传输网络的能源议题。
- [Google碳感知计算](https://sustainability.google/products/carbon-aware-computing/)：碳感知调度相关说明。
- [Microsoft碳感知计算文档](https://learn.microsoft.com/en-us/azure/carbon-aware/)：开发者文档；不是所有场景都适用。

## 欧盟CBAM：谨慎使用

- [欧盟委员会CBAM页面](https://taxation-customs.ec.europa.eu/carbon-border-adjustment-mechanism_en)

CBAM只适用于法规列明的商品、主体和核算规则，不能仅因为研究对象涉及“出口”就默认AI服务或数字服务直接受其约束。若研究合规成本，先确认具体法律条款、覆盖产品、报告义务与适用日期；不确定时不要套用碳价。

## 怎么判断资料是否可靠

1. 优先回到标准发布机构、监管机构、论文原文或数据提供者页面；
2. 核对版本、发布日期、地区、适用范围和单位；
3. 记下访问日期；
4. 用官方原文支持关键事实，不只引用新闻报道；
5. 如果来源互相矛盾，把差异记录下来，不要默默挑一个数字。
