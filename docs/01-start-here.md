# 01｜入门路线：先搞清问题，再学工具

## 你想研究的事，用一句话说

不同机构或厂商在计算AI服务碳排放时，可能用了不同的计算边界和数据；这些差异会让结果相差多少？这种不确定性会不会增加企业披露、审计或市场准入的成本？

这只是研究方向的拆解，不是已经证明的结论。最后结论必须由你的资料和分析支持。

## 先做一件小事：选定“比较的任务”

例如，假设你选“一个视觉模型识别1000张图片”。你需要说明图片大小、任务质量要求、模型版本和运行环境。不要把它和“训练另一个模型一年”直接比较，因为两者不是同一项任务。

研究时可以从下列小问题选一个：

- 同一项AI任务，不同电力碳强度假设会让估算变化多少？
- 有无计入数据中心冷却，会改变估算多少？
- 厂商公开资料中，哪些关键核算信息常常缺失？
- 如果只报告运行用电，和报告完整生命周期相比，边界差在哪里？

## 六阶段路线

| 阶段 | 做什么 | 完成标志 |
|---|---|---|
| 1. 读规则 | 到赛事官网查看当届报名、投稿和AI使用规则 | 保存官方通知和核验日期 |
| 2. 缩小问题 | 选一个服务、一个功能单位、一个口径差异 | 用三句话说明研究问题 |
| 3. 建证据表 | 收集公开资料，逐条记录来源、年份、单位和限制 | 任何数字都能追到来源 |
| 4. 做简单计算 | 用可解释的公式先算运行用电排放 | 能复算，假设明确 |
| 5. 做敏感性分析 | 改变一个关键输入，观察结果变化 | 能指出最影响结果的变量 |
| 6. 学视觉与算力 | 用一个小型图像分类任务理解推理 | 记录模型、数据、运行时间和环境 |

## 重要的边界

- 初期可只研究运行用电，但必须把结论称为“运行阶段估算”，不能称为完整生命周期结果。
- 不要在没有证据时推算企业实际合规成本。可以先研究可能的成本类别，并说明需要何种数据才能估算。
- 竞赛规则可能更新。投稿前以赛事官网当届文件为准。
- AI助手可以解释概念、帮助调试学习代码和检查计算；不能替你生成参赛作品，也不能替代来源核验。

## 你每周可以留存的成果

一页阅读笔记、一个数据表、一段可运行代码、一张带单位和来源的图，或者一份明确写出局限的实验记录。小而可信的成果比大而不可复现的“结论”有用。
